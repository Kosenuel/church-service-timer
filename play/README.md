# Google Play listing

- `listing/en-GB/`: app name, short and full description for the store listing.
- `graphics/`: icon, feature graphic, and phone and tablet screenshots, made from the app's golden previews (test data only) by `node scripts/play_assets.js`.

See [docs/PLAY-RELEASE.md](../docs/PLAY-RELEASE.md) for where each one goes and the full publishing checklist.
