# Menu appearance consistency · 0.20.1

The Start service program chooser now follows the appearance settings selected on this device: Compact, Comfortable, Spacious or Automatic, and Subtle, Strong or Hidden dividers. Program names and duration summaries wrap naturally; long lists scroll. Selecting a program still loads Ready and requires the existing confirmation to start timing.

The same settings now cover the previously missed warning actions, cue actions, program list options, stage-cue chooser, program-import review, suggested-duration choices and Print Service options. Dropdown choice sheets, jump destinations and program/report menus use the shared spacing. The rundown detail sheet also follows the selected padding and divider style.

Delete actions remain visibly separated even with Hidden dividers. Menu touch targets remain at least 48 logical pixels, and Automatic resolves using the device's screen size. These are local appearance preferences; service timing, pairing and LED output behavior are unchanged.

Android's own file picker, print/save screen and system permission dialogs retain the operating system's appearance.
