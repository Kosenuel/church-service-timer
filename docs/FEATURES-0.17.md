# 0.17 — Stage shortcuts and refined controls

The Live welcome card now offers **Join as stage screen**. It opens the existing six-digit/QR pairing page with Stage display selected. New receivers still require host approval. The shortcut is absent while this phone runs a service; opening it and going back preserves the local program. A phone already hosting confirms before entering the join flow and stops hosting only when a join is attempted. A saved viewer/stage host can be resumed directly as a stage screen; a saved operator connection requires the normal operator join flow.

Mobile-screen host actions use **Share to stage screens**, distinguishing sending from receiving. Paired devices retains **Share this service** for sharing controls while keeping an LED or Simulator destination. **Go to Live** appears in the header of Paired devices and Stage screens and returns directly to Live without stopping sharing. The prominent Stop sharing action remains available.

Quick messages remain available after End service when an approved stage screen is connected, sharing is enabled and this phone has control. Sending then requires confirmation, including **Sending to N stage screen(s)**. The same recipient count appears above the composer. Cancel leaves the draft intact and sends nothing. A confirmed message does not restart the service or alter its saved report. Expiry or **Clear message** restores the end screen, or the intentional blank state that preceded the message. Disconnected receivers do not replay missed messages. Messages remain temporary and are not restored after an app restart. Sending before any service has run remains disabled; Test screen is available for setup.

Selections across program editing, service mode, cue formatting, warning destinations, quick messages, joining and printing now use consistent theme-aware controls. Short choices remain visible as wrapping chips. Longer choices open a rounded bottom sheet with the current selection marked, and lists longer than eight options offer search. Back, Close or tapping outside cancels without changing the selection. The controls support light/dark palettes and larger text.

On LED connection, **Remember password on this phone** is checked by default and sits below the password entry. It stores the LED device connection password in the existing Android Keystore-encrypted local vault; it does not store or change the Wi-Fi password. Unchecking removes an existing saved copy without disconnecting the active sign. A cached credential can finish that connection attempt, but it is not saved again unless the operator rechecks the option. Removal errors leave the checkbox checked and show a retry message. Forget display continues to delete its saved credential. These credentials are excluded from portable backups and diagnostics.

Print Service rundown documents omit **Planned start**. They retain segment number, segment/speaker and duration, the service date, optional banner and opt-in private notes. Historical full reports retain Planned duration, Actual and Paused columns; their values still come from the recorded service.

Both Matrix fonts, LED serialization and controller administration are unchanged. This release is verified with automated state, encrypted loopback and UI tests. Hands-on testing is left to the user; no phone or sign interaction is part of that automated evidence.
